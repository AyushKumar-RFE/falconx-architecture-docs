# Confluence bridge

Confluence is **not** the architecture SSOT ([ADR 0002](/adr/0002-git-docs-as-ssot)).

Use it to:

1. Publish a **hub page** that links to this site / repo ([template](./hub-template))
2. **Discover** existing pages and import them into git via Atlassian MCP ([import workflow](./import-workflow))
3. Share exec-friendly summaries that point back here for detail

## Connect

Follow [Connect MCP](./connect-mcp) — Atlassian Rovo MCP (`https://mcp.atlassian.com/v1/mcp/authv2`).
